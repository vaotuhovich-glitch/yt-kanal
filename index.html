yt-kanal

Личный инструмент владельца YouTube-канала: читает статистику собственного канала через официальные API YouTube. Доступ только на чтение, других пользователей нет.

A personal read-only tool that lets the channel owner read their own YouTube channel statistics through the official YouTube APIs. It has no other users.
